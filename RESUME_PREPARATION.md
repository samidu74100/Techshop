## 📋 Actions Manuelles Requises

Les étapes suivantes nécessitent votre intervention:

### Étape 1: Créer un Repo GitHub (2 min)
1. Aller sur https://github.com/new
2. Nom: `techshop`
3. Public
4. **NE PAS** ajouter README
5. Créer

### Étape 2: Pousser le Code (1 min)
```bash
git remote add origin https://github.com/VOTRE_USERNAME/techshop.git
git push -u origin main
```
⚠️ Remplacer `VOTRE_USERNAME` par votre username GitHub!

### Étape 3: Déployer sur Vercel (3 min)
1. Aller sur https://vercel.com/signup
2. Login avec GitHub
3. "Add New" → "Project"
4. Import "techshop"
5. Deploy!
